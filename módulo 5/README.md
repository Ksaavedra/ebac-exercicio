# Módulo 5 - Documento HTML Simples

## 📋 Descrição

Este módulo contém uma página HTML simples que demonstra conceitos básicos de desenvolvimento web, incluindo estrutura HTML, estilização com CSS e integração com JavaScript. A página exibe uma imagem de uma cachorra com um título.

## 🎯 Funcionalidades

-  Exibição de uma página HTML básica
-  Título "Minha cachorra"
-  Imagem da cachorra
-  Integração com JavaScript para validação de funcionamento
-  Estilização básica com CSS

## 🛠️ Tecnologias Utilizadas

-  **HTML5** - Estrutura básica da página
-  **CSS3** - Estilização simples (background e fonte)
-  **JavaScript (Vanilla)** - Console log para verificação

## 📁 Estrutura de Arquivos

```
módulo 5/
├── index.html              # Página principal HTML
├── index.css               # Estilos da página
├── index.js                # Script JavaScript
├── images/
│   └── cachorra.png        # Imagem da cachorra
└── README.md               # Documentação
```

## 🚀 Como Usar

1. Abra o arquivo `index.html` em um navegador web
2. A página será exibida com o título e a imagem
3. Abra o console do navegador (F12) para verificar a mensagem do JavaScript

## 📝 Detalhes da Implementação

### HTML (`index.html`)

-  Estrutura básica de documento HTML5
-  Título `<h1>` exibindo "Minha cachorra"
-  Tag `<img>` carregando a imagem da cachorra
-  Script externo vinculado

### CSS (`index.css`)

-  Estilização do corpo da página
-  Cor de fundo cinza claro (#f5f5f5)
-  Fonte Arial, Helvetica ou sans-serif

### JavaScript (`index.js`)

-  Console log simples para verificar o funcionamento do JavaScript
-  Mensagem: "JavaScript funcionando!"

## 🖼️ Imagem

A imagem `cachorra.png` está localizada na pasta `images/` e é exibida com largura de 120 pixels.

## ✨ Objetivos de Aprendizado

Este módulo é útil para:

-  Entender a estrutura básica de um documento HTML
-  Aprender a vincular arquivos CSS e JavaScript externos
-  Trabalhar com imagens em HTML
-  Verificar o funcionamento do JavaScript no navegador
