# EBAC - Exercícios Frontend

## 📚 Sobre o Projeto

Este repositório contém os exercícios e projetos desenvolvidos durante o **curso de Frontend da EBAC** (Escola Britânica de Artes Criativas & Tecnologia), focado em **JavaScript**, **HTML** e **CSS**.

## 🎯 Objetivo do Curso

Aprender os fundamentos e técnicas essenciais para desenvolvimento frontend, incluindo:

-  **HTML5** - Estruturação e semântica de páginas web
-  **CSS3** - Estilização, layout e design responsivo
-  **JavaScript** - Programação para interatividade e manipulação do DOM

## 📁 Módulos do Curso

### Módulo 4 - Calculadora de IMC

Uma calculadora interativa de Índice de Massa Corporal (IMC) desenvolvida com HTML, CSS e JavaScript puro.

**Arquivos:**

-  `formulario.html` - Página principal
-  `estilo.css` - Estilos da aplicação
-  `script.js` - Lógica de cálculo

[Ver detalhes do Módulo 4](./módulo%204/README.md)

### Módulo 5 - Documento HTML Simples

Página HTML básica demonstrando conceitos fundamentais de estruturação, estilização e integração com JavaScript.

**Arquivos:**

-  `index.html` - Página principal
-  `index.css` - Estilos básicos
-  `index.js` - Script JavaScript
-  `images/cachorra.png` - Imagem de exemplo

[Ver detalhes do Módulo 5](./módulo%205/README.md)

### Módulo 6 - Jogo de Adivinhação (1 a 100)

Jogo em JavaScript onde o computador escolhe um número secreto de 1 a 100 e o jogador tenta adivinhar com dicas de “maior/menor” e número máximo de tentativas.

**Arquivos:**

-  `index.html` - Página principal
-  `style.css` - Estilos do jogo
-  `script.js` - Lógica do jogo

[Ver detalhes do Módulo 6](./módulo%206/README.md)

## 🛠️ Tecnologias Utilizadas

-  **HTML5**
-  **CSS3**
-  **JavaScript (ES6+)**

## 📖 Como Executar os Exercícios

Cada módulo é independente e pode ser executado diretamente:

1. Navegue até a pasta do módulo desejado
2. Abra o arquivo `.html` em um navegador web moderno
3. Para depuração, use as ferramentas de desenvolvedor do navegador (F12)
